১। সঠিক শব্দ নির্বাচন করে উত্তর লেখো:

  1. আর্যসত্য (বৌদ্ধ / জৈন / আজীবিক) ধর্মের অংশ।
  2. গৌতম বুদ্ধ জন্মেছিলেন (লিচ্ছবি / হর্যঙ্ক / শাক্য) বংশে।
  3. পার্শ্বনাথ ছিলেন (মগধের রাজা / বজ্জিদের প্রধান / জৈন তীর্থংকর)।
  4. মহাজনপদগুলি গড়ে উঠেছিল — (খ্রিঃ ষষ্ঠ শতকে / খ্রিঃ পূঃ ষষ্ঠ শতকে)।
  5. জনপদ হোল (কৃষিভিত্তিক / শিল্পভিত্তিক / শ্রমভিত্তিক) গ্রামীণ এলাকা।
  6. গুপ্ত ও গুপ্ত পরবর্তী আমলে ধর্মীয় উদ্দেশ্যে জমিদানকে বলা হয় (সামন্ত / বেগার / অগ্রহার) ব্যবস্থা।
  7. মৌর্য আমলে অর্থনীতি মূলত (শিল্পের / কৃষির / ব্যবসা বাণিজ্যের) উপরে নির্ভর করে।
  8. সেন্ট থমাস খ্রিষ্টধর্ম প্রচারের জন্য ভারতীয় উপমহাদেশে এসেছিলেন (আলেকজান্ডার / মিনান্দার / গন্ডোফারনেস)-এর অঞ্চলে।
  9. ইন্দো-গ্রিক চলন হোত (শকদের / ব্যাকট্রিয়ার অধিবাসীদের / কুষানদের)।
  10. হেরোডোটাসের মতে ইন্ডুস ছিল পারসিক সাম্রাজ্যের একটি (প্রদেশ / দেশ / জেলা)।

২। বেমানান শব্দটি খুঁজে বের করে তার নিচে দাগ দাও:

  1. রত্নাবলী, মৃচ্ছকটিকম, অর্থশাস্ত্র, অভিজ্ঞান শকুন্তলম।
  2. নালন্দা, তক্ষশিলা, বলভী, পাটলিপুত্র।
  3. ব্রাহ্মী, সংস্কৃত, খরোষ্ঠি, দেবনগরী।
  4. বৃদ্ধযশ, কুমারজীব, পরমার্থ, সুয়ান জাং।
  5. আলেকজান্ডার, সেলুকাস, কনিষ্ক, মিনান্দার।

৪। নীচের বাক্যগুলির কোনটি ঠিক কোনটি ভুল তা লেখো:

  1. নালন্দা মহাবিহারে কেবল ব্রাহ্মণ ছাত্ররাই পড়তে পারত।
  2. বাগভট্ট ছিলেন একজন চিকিৎসক।
  3. কুষানরা এদেশেরই মানুষ ছিলেন।
  4. আলেকজান্ডার গ্রীসদেশের ম্যাসিডন রাজ্যের রাজা ছিলেন।
  5. কম্বনের রামায়ণে রামকেই বড়ো করে দেখানো হয়েছে।
